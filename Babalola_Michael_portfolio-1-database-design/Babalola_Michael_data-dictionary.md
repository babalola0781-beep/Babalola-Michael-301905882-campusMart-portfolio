# Relational schema and data dictionary

PK = primary key; FK = foreign key; UQ = unique alternate key. Every listed
column is NOT NULL. Identity keys are generated by PostgreSQL and must not be
manually assigned during normal inserts.

## Relational schema

- CUSTOMERS(**customer_id** PK, full_name, email UQ)
- CATEGORIES(**category_id** PK, category_name UQ)
- PRODUCTS(**product_id** PK, category_id FK -> CATEGORIES, sku UQ,
  product_name, price, stock_quantity)
- ORDERS(**order_id** PK, customer_id FK -> CUSTOMERS, order_reference UQ,
  order_date, status)
- ORDER_ITEMS(**order_id, product_id** composite PK; order_id FK -> ORDERS;
  product_id FK -> PRODUCTS; quantity, unit_price)

## Columns

| Table.column | PostgreSQL type | Meaning / rules |
|---|---|---|
| customers.customer_id | BIGINT identity | Generated customer key |
| customers.full_name | VARCHAR(100) | Nonblank display name |
| customers.email | VARCHAR(254) | Unique, lower-case, trimmed; basic @ check |
| categories.category_id | BIGINT identity | Generated category key |
| categories.category_name | VARCHAR(80) | Unique nonblank label |
| products.product_id | BIGINT identity | Generated product key |
| products.category_id | BIGINT | Existing category; deletion restricted |
| products.sku | VARCHAR(20) | Unique nonblank stock-keeping code |
| products.product_name | VARCHAR(120) | Nonblank label |
| products.price | NUMERIC(12,2) | Current unit price in NGN; non-negative, not NaN |
| products.stock_quantity | INTEGER | Current stock; default 0; non-negative |
| orders.order_id | BIGINT identity | Generated order key |
| orders.customer_id | BIGINT | Existing customer; deletion restricted |
| orders.order_reference | VARCHAR(20) | Unique nonblank business reference |
| orders.order_date | TIMESTAMPTZ | Instant of creation; default CURRENT_TIMESTAMP |
| orders.status | VARCHAR(15) | draft / placed / completed / cancelled; default draft |
| order_items.order_id | BIGINT | Part of PK; existing order; deletion restricted |
| order_items.product_id | BIGINT | Part of PK; existing product; deletion restricted |
| order_items.quantity | INTEGER | Positive whole number |
| order_items.unit_price | NUMERIC(12,2) | Historical charged unit price in NGN |

TIMESTAMPTZ stores a time instant and displays it using the session's time zone;
it does not retain the original textual offset. Sample timestamps use +01:00.
NUMERIC(12,2) supplies 12 total digits, two after the decimal point, suitable for
the chosen teaching dataset. Identity keys can have gaps; they are identifiers,
not row counters.

## Relationship cardinalities

| Parent -> child | Children per parent | Parents per child |
|---|---|---|
| customers -> orders | 0..many | Exactly 1 |
| categories -> products | 0..many | Exactly 1 |
| orders -> order_items | 0..many | Exactly 1 |
| products -> order_items | 0..many | Exactly 1 |

The many-to-many order/product relationship is resolved by ORDER_ITEMS.
The order's zero lower bound reflects drafts and the actual schema; the intended
minimum of one item for a placed order requires workflow enforcement.
